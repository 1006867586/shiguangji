# 想聚（飨刻）微信小程序 UI 对齐设计稿 — 设计文档

- 日期：2026-08-16
- 分支：weapp
- 设计稿：https://ardot.tencent.com/file/715371942850999（Page 1，375×812，designWidth=750 → rpx ×2）
- 范围：weapp/ 目录内视觉层重做；**保功能 + 真数据，只重样式**
- 品牌名：**飨刻**（设计稿登录屏写「想聚」，按用户确认统一用「飨刻」）

## 背景与目标

将 Ardot 设计稿（6 屏 + 悬浮胶囊 Tab Bar）在现有 Taro 4 + React 小程序上实现。
现有小程序已接入真实后端（Supabase/Next.js API：feed、圈子、转盘、登录、发布、收藏等），
本次只重做视觉层，不改变数据流与交互逻辑；设计稿中有而后端接口没有的字段（如商家距离、
个人统计数、圈子动态数）一律隐藏而非造假。

用户本地已有未提交改动（custom tab bar 机制、tabStore、has-tabbar 留白、转盘本地默认菜系），
已作为 checkpoint 提交（6788879），本设计在其基础上继续。

## 实现方案

**方案 A：逐单元重写**（已确认）。顺序：0 令牌 → 1 Tab Bar → 2 登录 → 3 动态 → 4 圈子 → 5 发布 → 6 我的 → 7 转盘。
每阶段构建 + 开发者工具截图验证（必要时用 modlens 与设计稿对比）。

## 1️⃣ Tab Bar（悬浮胶囊）— `src/custom-tab-bar/`

保留现有机制（`tabBar.custom: true`、`tabStore.ts`、页面 `has-tabbar` 留白、`useDidShow` 里 `setSelectedTab`），
**重写 `index.tsx` + `index.scss` 的视觉为悬浮胶囊**：

- 容器：固定底部居中悬浮，白底胶囊约 `670×124rpx`，`border-radius: 72rpx`，1rpx 边框 `#F0EDE8`，阴影 `0 2rpx 12rpx rgba(0,0,0,.08)`；距底部留安全区
- 5 项：动态(home) / 圈子(groups) / 发布(plus，居中) / 转盘(wheel) / 我的(user)，SVG 线条图标 + 中文标签
- 选中态：图标外 **橙色实心圆**（约 88rpx），标签橙色加粗；发布键居中凸起，渐变圆底（`#FF6B35→#FFA940`）+ 白色 + 号
- 未选中：灰色线条图标 `#9CA3AF` + 灰标签
- 发布 tab 仍是 `switchTab` 到 `/pages/publish/index`（保持 tab 语义，不做非 tab 跳转）

## 2️⃣ 登录页 `src/pages/login/`

- 全屏珊瑚渐变底（`#FF6B36 → #FF8C42`，约 135°）
- 中部：飨刻 logo（笑脸图标）+ 品牌名「飨刻」+ 副标题「聚餐不将就，点餐更轻松」
- 底部：微信一键登录按钮（白底/或微信绿底按现有规范）、协议文案「登录即同意《用户协议》和《隐私政策》」
- 保留现有登录流程（`Taro.login` → `/api/auth/weapp/login`），仅重样式

## 3️⃣ 动态页 `src/pages/index/`

- 头部「动态」+ 搜索图标（无搜索后端 → 隐藏搜索图标）
- 圈子切换：现有 `group-tabs` 重做为设计稿**筛选胶囊**（横向滚动、圆角胶囊、选中实橙底白字），逻辑不变（首个圈子默认选中）
- Feed 卡片（复用 `ActivityCard`，重样式）：
  - 头像/昵称/相对时间；转发徽标与附言（`repost_comment`）
  - 正文、图集（`PhotoGrid`）
  - 商家卡：平台标签、店名、评分 `★ 4.8`、人均 `¥120/人`（`external_link.rating/price`）；**距离字段后端无 → 隐藏**
  - 操作栏：点赞（心形，选中珊瑚红）、评论数、分享、海报
- 页面背景暖米 `#FAF7F2`，卡片白 + 轻阴影 + 圆角

## 4️⃣ 圈子页 `src/pages/groups/`

- 头部「圈子」+ 右上橙色 + 按钮（新建/加入）
- 群组卡片列表：图标（群头像）、名称、成员数·动态数（`member_count` 有则显示；动态数后端无 → 隐藏）、简介、右侧按钮（「已加入」灰态 /「加入」珊瑚实心）
- 保留现有创建/加入圈子流程

## 5️⃣ 发布页 `src/pages/publish/`

- 顶栏：「取消」/「发布」（发布为珊瑚实心胶囊）
- 圈子选择器（现有逻辑，设计稿分类选择器语义 = 当前圈子选择）
- 多行正文输入（占位「分享你的聚餐故事…」）
- 图片上传格（现有照片选择/上传流程）+ 附件工具图标行（相机/链接等按现有能力保留）
- 保留现有发布流程（内容、美团/点评链接解析、照片上传）

## 6️⃣ 我的页 `src/pages/profile/`

- 橙色渐变头部：头像 + 昵称 + 统计行（动态/好友/圈子；后端无对应统计接口 → 显示已有数据或隐藏整行，不造假）
- 菜单列表（图标 + 文案 + 右箭头），**仅列出有真实落地页的项**（后端/页面不存在的菜单不造假）：
  - 我的圈子 → `/pages/groups/index`
  - 我的收藏 → `/pages/favorites/index`
  - 设置/退出登录 → 保留现有 profile 页能力
  - 我的动态 → 当前无专用「我的动态」页：**该项不显示**（除非后续新增页面，本次不做）
- 保留现有登录态、头像昵称展示逻辑

## 7️⃣ 转盘页 `src/pages/roulette/`

- 标题「今天吃啥？」+ 副标题「转一转，告别选择困难」
- **6 色转盘**（canvas 重绘，设计稿色值）：
  - 西餐 `#4A4AE8`、火锅 `#FF6B3D`、日料 `#FFA040`、烧烤 `#FF8C42`、川菜 `#F25C7A`、粤菜 `#3DC2B8`
- 中心白色 GO 键（橙色描边圆环），顶部黑色三角指针
- 「最近结果」区：胶囊 chips（最近 3 次，首项高亮浅橙底）
- 保留用户已改的本地默认菜系（DEFAULT_CUISINES）+ 圈子候选（`fetchMealRoulette`）双模式

## 数据 / 功能边界

- 所有现有 API 调用与状态逻辑不变（登录、feed 分页、点赞、圈子 CRUD、发布、收藏、转盘候选）
- 仅当某设计元素无对应数据时隐藏；不新增假数据
- 图标统一内联 SVG（Taro 支持），避免引入图标字体
